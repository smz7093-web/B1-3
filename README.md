# 1. 과제 개요

## 프로젝트 1. 자동화 도구 비교 구현
동일한 자동화 워크플로우를 **서로 다른 2개 이상의 자동화 도구**로 구현하고 비교 분석합니다.

### 포함 내용
- 동일한 워크플로우를 2개 이상의 도구로 구현
- 각 도구별 워크플로우 구성 화면 캡처
- 각 도구별 실행 결과 화면 캡처
- 비교 분석 보고서 작성

---

## 프로젝트 2. 자유 주제 자동화 설계 및 구현
실제 반복 업무 1개를 선정하여, 적절한 자동화 도구를 선택하고 자동 실행되도록 구현합니다.

### 포함 내용
- 자동화할 반복 업무 정의
- 자동화 도구 1개 선정 및 선정 이유 작성
- 워크플로우 설계 문서 작성
- 구현 화면 캡처
- 실행 결과 화면 캡처
